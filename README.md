# -Simulation-and-Statistical-Analysis-of-Fungal-Clearance-in-Cryptococcal-Meningitis
Simulates clinical data to evaluate 7-, 14-, and 21-day antifungal induction regimens for cryptococcal meningitis. Uses R to generate fungal burden data, apply ANOVA &amp; Tukey HSD tests, and visualize outcomes to support evidence-based recommendations for treatment duration.
